## 1. Product Overview
美团代理商财务数据分析工具，用于管理河北省10个城市的财务数据，提供概览、维度下钻、趋势分析和敏感性分析功能。
- 目标用户：美团代理商运营总监辛昕
- 核心价值：直观展示财务数据，支持决策优化业务结构

## 2. Core Features

### 2.1 User Roles
| Role | Registration Method | Core Permissions |
|------|---------------------|------------------|
| 运营总监 | 直接访问 | 所有功能 |

### 2.2 Feature Module
1. **概览页（Tab1）**：总商核心指标卡片、城市综合排名
2. **维度下钻页（Tab2）**：业务模块×商家类型，完整指标展示
3. **趋势分析页（Tab3）**：历史数据趋势，线性回归分析
4. **敏感性分析页（Tab4）**：参数调整模拟，结果对比

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 概览页 | 总商核心指标卡片 | 7项核心指标横向展示 |
| 概览页 | 城市综合排名表 | 10个城市UE、毛利率综合排名 |
| 维度下钻页 | 筛选条件 | 城市多选、业务模块切换 |
| 维度下钻页 | 指标层级展示 | 可折叠的完整指标树 |
| 趋势分析页 | 筛选条件 | 城市单选、商家类型切换、时间范围 |
| 趋势分析页 | 趋势分析表 | 完整指标历史数据+趋势强度+R²+结论 |
| 敏感性分析页 | 参数调整 | 业务模块占比、商家类型占比、配送类型占比、成本率 |
| 敏感性分析页 | 结果对比 | 原始值vs调整后对比、业务模块贡献变化 |

## 3. Core Process
用户导入Excel账单数据 → 选择城市和业务模块查看详情 → 发现异常 → 查看历史趋势分析 → 模拟参数调整 → 保存方案 → 决策

```mermaid

    A[导入Excel] --> B[查看概览]
    B --> C[维度下钻分析]
    C --> D[发现异常]
    D --> E[趋势分析]
    E --> F[敏感性分析]
    F --> G[保存方案]
```

## 4. User Interface Design
### 4.1 Design Style
- 主色：深蓝色（专业商务），辅助色：绿色（健康/上涨）、红色（危险/下跌）
- 按钮：圆角矩形，微立体阴影
- 字体：现代无衬线，清晰易读
- 布局：卡片式，左右分栏（左侧筛选，右侧内容）
- 图标：简洁实用的商务风格

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 所有页面 | 顶部导航 | Logo、4个Tab切换按钮 |
| 概览页 | 指标卡片 | 白色背景，浅阴影，数值放大显示 |
| 维度下钻页 | 指标树 | 可折叠层级，父指标加粗，子指标缩进 |
| 趋势分析页 | 趋势表 | 时间轴横向排列，趋势方向用箭头表示 |
| 敏感性分析页 | 参数滑块 | 实时联动，总和保持100% |

### 4.3 Responsiveness
- Desktop-first，支持1080p及以上分辨率
- 移动端适配为垂直滚动布局
- 表格和图表在小屏幕上可横向滑动

### 4.4 特殊说明
- 涨跌颜色与股市相反：涨绿跌红
- 阈值基于真实数据分布动态调整
