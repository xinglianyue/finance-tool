# 世界级财务分析工具设计指南

## 用户旅程设计

### 1. 数据导入阶段
- 数据预览（头5行）
- 数据质量检查（完整性、一致性）
- 自动数据类型识别

### 2. 探索阶段（Dashboard）
- 关键指标概览（KPI卡片）
- 业务结构分析（占比图）
- 趋势变化（时间序列）
- 快速发现异常（红色预警）

### 3. 深度分析阶段
- 多维度钻取（城市→模块→时间）
- 成本结构分解图
- 利润率分析
- 对比分析（vs历史/vs预期）

### 4. 决策阶段
- 异常根因分析
- 优化建议
- ROI计算器
- 优先级排序

### 5. 行动阶段
- 待办清单
- 进度追踪
- 效果复盘

## 核心分析维度（必看）

### 1. 业务结构分析
- 各业务收入/利润占比
- 业务贡献度矩阵（大小=规模，颜色=UE）

### 2. 成本结构分析
- 固定成本 vs 可变成本
- 成本占收入比
- 边际成本分析

### 3. 盈利能力分析
- 毛利率 vs 净利率
- 各业务ROI
- 边际贡献分析

### 4. 规模与效率
- 规模经济曲线
- 单位订单成本
- 人效/坪效指标

## 交互式设计原则

### 1. 从概览到细节（Drill-down）
- 总览 → 区域 → 城市 → 模块
- 时间：年度 → 季度 → 月度 → 日

### 2. 对比分析
- 时间对比（环比/同比）
- 基准对比（vs目标/vs同行）
- 场景对比（A/B测试）

### 3. 可视化最佳实践
- 关键指标：大数字卡片
- 占比：饼图/环形图
- 趋势：折线图
- 对比：柱状图
- 结构：堆叠柱状图
- 关联：散点图/气泡图

## 数据叙事逻辑（Storytelling）

### 优秀的财务报告应该回答：
1. 我们做得怎么样？（健康度）
2. 哪里有问题？（异常识别）
3. 为什么会这样？（根因分析）
4. 我们应该怎么办？（行动建议）
5. 预期会有什么效果？（ROI预测）

## 世界级工具案例分析

### Tableau
- 强调数据探索（拖拽式）
- 多维度联动
- 数据故事板

### Power BI
- 与Excel深度集成
- DAX语言强大分析
- 实时数据流

### QuickBooks
- 财务导向
- 自动对账
- 税务合规

### SAP Analytics Cloud
- 企业级
- 预测分析
- 协作功能

## 我们的工具应具备的特色

### 1. 美团业务适配
- 外卖/闪购/拼好饭/医药业务建模
- 补贴结构分析
- 配送成本优化

### 2. 简单但不简陋
- 3步即可完成分析
- 复杂逻辑自动处理
- 结果清晰易懂

### 3. 行动导向
- 不仅发现问题，更给出方案
- 建议有优先级和ROI估算
- 可追踪执行进度
